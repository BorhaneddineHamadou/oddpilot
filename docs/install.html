Download & install — step by step

Ten minutes from nothing to your first physics-checked scenario. Works the same on Linux, macOS and Windows; every block is copy-paste ready.

What you need first

RequirementCheck withIf missing
Python 3.10 or newerpython3 --version (Windows: py --version) Install from python.org — on Windows, tick “Add python.exe to PATH”.
gitgit --version git-scm.com — or skip git entirely and use the ZIP download in step 1.

No simulator, no GPU, no admin rights needed. odd-pilot is plain Python and never talks to the network at runtime.

Install, step by step

1Get the code

git clone https://github.com/BorhaneddineHamadou/oddpilot.git
cd oddpilot

No git? On the GitHub page click Code → Download ZIP, unpack it, and open a terminal in the unpacked folder instead.

2Create a virtual environment (recommended, keeps your system Python clean)

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

# Windows (PowerShell)
py -m venv .venv
.venv\Scripts\Activate.ps1

Your prompt now shows (.venv). Re-run the activate line whenever you open a new terminal.

3Install

# the linter only — one lightweight dependency (PyYAML)
pip install -e physcheck/

# ... or the full campaign copilot (adds pandas + pgmpy)
pip install -e physcheck/ -e odd-pilot/

4Verify — lint the shipped examples

The repository ships three deliberately broken scenarios and three clean ones, exactly for this moment:

physcheck --version
physcheck lint examples/violating        # must report errors …
physcheck lint examples/valid            # … and this must be clean

You should see findings like “midnight sun” and “impossible kinematics” on the first command, and a clean pass on the second. If both behave as described, you are done installing.

Your first real lint

# point it at any folder of .xosc files
physcheck lint path/to/your_scenarios/

# with your OpenDRIVE map: adds the map and motion checks (L2+L3)
physcheck lint path/to/your_scenarios/ --map your_map.xodr

# see warnings too, and save a shareable web report
physcheck lint your_scenarios/ --severity warning --format html -o report.html

# understand any finding in depth (rule text, threshold, literature source)
physcheck rules show KIN-018

From there, the campaign copilot page walks through measuring coverage and generating the tests you are missing — and the rule reference documents all 157 checks.

Which package do I need?

You want to…InstallCommands you get
Check scenario files for physics/consistency problems (most users start here) pip install -e physcheck/ physcheck lint, physcheck rules
Also measure coverage adequacy, generate gap-targeted tests, produce evidence reports, drive the whole loop pip install -e physcheck/ -e odd-pilot/ everything above + odd-pilot model / assess / gaps / plan / report / conform / loop
Develop or run the test suite pip install -e "physcheck/[dev]" -e "odd-pilot/[dev]" + pytest, ruff, mypy
PyPI packages (pip install physcheck without cloning) are planned; until then the editable install above is the supported path.

Updating

cd oddpilot
git pull            # fetches the newest rules and features

Editable installs pick the update up immediately — no reinstall needed. Check what changed with git log --oneline -10.

Troubleshooting

SymptomFix
physcheck: command not found The virtual environment is not active — re-run the activate line from step 2. (Or call it as python3 -m physcheck.cli lint ….)
python3: command not found (Windows) Use py instead of python3 everywhere.
pip fails building pgmpy/pandas Those are only needed by odd-pilot. Install just physcheck/ first; upgrade pip (pip install --upgrade pip) before retrying the rest.
Air-gapped machine / no PyPI access physcheck needs only PyYAML: copy the repo plus a PyYAML wheel and pip install --no-index them. The tool itself makes no network calls.
note: map cross-checks skipped … Not an error: L2/L3 need an OpenDRIVE map. Pass --map file.xodr or let each scenario's own RoadNetwork reference resolve.
Something else Open an issue with the command you ran and its full output.
